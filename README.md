# FoodLoop AI

**Food decision intelligence for school cafeterias.**

FoodLoop turns food waste from an end-of-process problem into a source of intelligence for the next meal.

## The loop
**Listen → Understand → Simulate → Experiment → Learn**

The prototype demonstrates:
- Student Voice
- Waste and root-cause insights
- Before-Serving Simulator
- Nutrition guardrails
- Small experiments and learning from outcomes

Built by **LoopLab** for **NextGen Innovator 2026**.

> Demo data are illustrative unless explicitly validated in a real pilot.
